# Contributing to DFPL

DFPL is specification-first. Please classify each contribution as one of:

- normative specification,
- formal proof/mechanization,
- conformance/test artifact,
- reference implementation,
- runtime/target profile,
- documentation,
- research/experimental.

For semantic changes, identify affected kernel components `G,T,N,IR,C,S,D`, compatibility/migration impact, tests, proof obligations, security implications, and whether Kernel identity changes.

Do not present historical conversational claims, simulations, prototypes, or experimental profiles as deployed, proven, or conformant without corresponding evidence.
